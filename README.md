# X-MADRL — Multi-Agent Disaster Response Dashboard

X-MADRL is a disaster-response dashboard designed to support hazard monitoring, situational awareness, risk assessment, and emergency-response planning.

## Features

- Interactive map for geographic situational awareness
- Disaster scenario visualization
- Hazard and location risk indicators
- Emergency route visualization
- Decision-support information for response planning

## Technology Stack

- React
- TanStack Start
- JavaScript
- Interactive mapping and data visualization libraries

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the development server using the script defined in `package.json`:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```

## Project Status

This project is under development. Data coverage, hazard detection, risk calculations, and routing should be validated before real-world emergency use.
